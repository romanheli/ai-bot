# ai-bot — паспорт проекта

Telegram-бот Epsilon: пользователь пишет вопрос — бот отвечает через Gemini (Google AI Studio, REST).
Пускает только id из ALLOWED_IDS (+ ADMIN_ID), в группах молчит. Запуск пока на ПК: `.venv\Scripts\python bot.py`.

## Что умеет
- Главное меню (/start и кнопка «Главное меню»): текст приветствия, курсивом «создатель - имя» ссылкой на профиль
  создателя (у Telegram нет мелкого шрифта), кнопка «отправить интимку автору» ведёт в тот же профиль.
  Меню исчезает после первого вопроса.
- Помнит последние 5 пар (вопрос, ответ) на пользователя — в памяти, при перезапуске пропадают.
- После первого ответа внизу появляются кнопки «Очистить сессию» и «Главное меню» и остаются постоянно.
- «Очистить сессию» — предупреждение «После очистки сессия не сохранится» с кнопками Принять/Отменить;
  при пустой истории сразу «Сессия уже пуста.». «Принять» удаляет все сообщения чата, которые бот видел
  с последнего запуска (Telegram не даёт удалять старше 48 ч), стирает историю и показывает
  «Сессия очищена.» + меню.
- Пока Gemini думает — «печатает…» (обновляется каждые 4 с).
- Ответ всегда одним сообщением: промпт просит ≤4096 символов, Markdown вычищается, длиннее 4096 — обрезка по абзацу с «…».
- Лог владельцу через отдельного лог-бота: вопросы (+ модель, время, первые 300 символов ответа), ошибки Gemini,
  попытки без доступа, очистка сессии, запуск бота, раз в неделю — «Недельный лимит Claude сбросился: дд.мм.гггг 03:00 МСК»
  (вс 00:00 UTC; если сервер в этот момент лежал — за эту неделю не придёт). Сломанный лог ответу не мешает.
- Модели: gemini-3.5-flash-lite, запасная gemini-3.1-flash-lite
  (404/429/5xx/таймаут — следующая; 400/403 — сразу ошибка).

## Файлы
- bot.py — настройки из .env, обработчики (build_dispatcher), typing, main.
- ai.py — запрос к Gemini (ask), clean/fit под Telegram.
- тесты: test_ai.py, test_bot.py, testutil.py (фейки Telegram и Gemini). `.venv\Scripts\python -m unittest`

## Настройки (.env, образец — .env.example)
BOT_TOKEN, LOG_BOT_TOKEN, ADMIN_ID, ALLOWED_IDS, GEMINI_API_KEY, CREATOR_USERNAME, необязательно GEMINI_MODELS, CREATOR_NAME.
CREATOR_USERNAME — username создателя, ссылка https://t.me/<username>. CREATOR_NAME — имя в меню, по умолчанию @username.
Лог-боту владелец должен один раз написать /start, иначе Telegram не даст ему писать.
